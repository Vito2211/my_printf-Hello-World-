# my_printf-Hello-World-
my_print("Hello World!") is a project aimed at building a simple computer from scratch using discrete electronic components in order to execute a program that outputs "Hello World!"
---

## 🧠 Project Idea

Instead of writing software on an existing computer, this project explores what a "computer" actually is by building one from the ground up:

- logic gates from transistors
- arithmetic circuits (adders)
- memory elements
- eventually a simple CPU

The end goal is to run a very small program that outputs **"Hello World!"**.

## 🛠️ Tools Used

- [Falstad Circuit Simulator](https://www.falstad.com/circuit/)
- Discrete electronic components (transistor-level logic design)
- Basic digital logic principles

---

## 🎯 Goals

- Understand how computation emerges from simple electronic switches
- Build a working minimal CPU from scratch
- Execute a simple instruction sequence
- Output "Hello World!" without using a prebuilt computer architecture

---

## ⚠️ Disclaimer

This is not an optimized or practical computer design.  
It is a learning / exploration project focused on understanding how computers work at the lowest level.

Expect:
- slow performance
- chaotic wiring
- occasional existential crises caused by carry propagation bugs
